## 1. 更新链路（最重要）

| | 官方 | 本版本 |

| 更新源 | `hiddify/Hiddify-Manager`（main / beta / dev） | 本 fork `dev-custom` |

仍指向官方、且**不影响二开**的：`packages.lock` 里的核心二进制、用户端 UI 的官方预构建包、v8 迁移包。

## 2. Manager

- **git 更新**：备份 → `fetch` → 快进合并 → 子模块 → `make build`，无需手工操作
- **小内存机**：直接装预构建管理端 UI，避免现场编译（约需 1.2 GB）
- **下载校验**：release 包 / 脚本失败即报错，不再静默降级到官方
- **配置安全**：先校验再重载 core / xray；失败步骤不再标成成功
- **运维**：残留 systemd 占 80/443 时回收进程；Redis 设内存上限 + `allkeys-lru`；WARP 只改端点端口；`app.cfg` 占位密钥自愈；`make debug` 可用

## 5. 已知限制

- **预发布**（tag 含 `b`）：`package_mode=release` 的服务器不会自动吃到；正式版请打 `v14.1.0`
- fork 需允许 GitHub Actions；客户端签名密钥缺失时 Release 只有说明、无安装包（需本地打）
- 面板硬依赖 MySQL + Redis（SQLite / fakeredis 不可用）
